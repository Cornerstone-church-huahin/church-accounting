# บัญชีคริสตจักร (Church Accounting)

PWA สำหรับบันทึกรายรับ งบประมาณ รอบนับเงินวันอาทิตย์ ใบเบิกจ่าย และรายงานพิมพ์ — ใช้บนมือถือเป็นหลัก ภาษาไทย
โครงเดียวกับ elder-handbook: เชิญด้วยลิงก์ · ผู้ใช้พิมพ์ชื่อ · แอดมินอนุมัติ · ข้อมูลเป็นไฟล์ JSON ใน repo **Private** `church-accounting-data`

## คำสั่ง
```bash
npm install
npm run dev        # เปิดทดสอบในเครื่อง
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บ (dist)
npm test           # ทดสอบตรรกะ (เงิน วันที่ อนุมัติ งบ จับคู่สเตตเมนต์)
npm run test:e2e   # วิ่งใช้งานจริงบนมือถือ 390px + ซิงก์ 2 เครื่องกับ GitHub จำลอง (ต้อง build ก่อน)
```

## สิทธิ์ 4 ระดับ (ค่าเริ่มต้น แก้ได้ที่ `src/lib/access.ts`)
| สิทธิ์ | ทำได้ |
|---|---|
| แอดมิน | ทุกอย่าง · จัดการผู้ใช้ ประเภทถวาย บัญชีธนาคาร งบประมาณ · อนุมัติใบเบิก |
| ผู้บันทึกบัญชี | บันทึกรายรับ นับเงิน นำฝาก อัปโหลดสเตตเมนต์ ทำใบเบิก จ่ายเงิน แนบใบเสร็จ |
| ผู้ตรวจสอบ | ดูทุกอย่าง · ยืนยันยอดนับคนที่ 2 · อนุมัติ/รับรองใบเบิกและใบเสร็จ · แก้ข้อมูลไม่ได้ |
| ดูอย่างเดียว | ภาพรวม งบประมาณ รายงาน (ไม่เห็นรายการรายตัว เลขอ้างอิง ใบเสร็จ) |

## กติกาที่ตั้งไว้เป็นค่าเริ่มต้น
- **ใบบันทึกการถวาย (วันอาทิตย์)**: ตามใบกระดาษจริง — ตู้ถวายแยกประเภท (จำนวนซอง + เงิน) ผู้ตรวจนับคนที่ 2 (คนละคน) ยืนยัน → นับเป็นรายรับ · เงินโอนจันทร์–อาทิตย์รวมในใบของวันอาทิตย์นั้น (แต่ละรายการมีเลขอ้างอิง เลขสมาชิก รูปสลิป ไม่บังคับแยกประเภท) · พิมพ์เป็นแบบฟอร์มได้ · นำเงินสดฝากธนาคารถ้ามี
- **ใบเบิก-จ่ายเงิน**: 1 ใบหลายรายการ (แต่ละรายการมีหมวดงบ และจ่ายโดย เงินสด/โอนจากบัญชีคริสตจักร/สำรองจ่าย) พิมพ์ตามแบบใบเบิกเดิมได้ · ยื่น → อนุมัติ → จ่าย → แนบใบเสร็จ → ผู้ตรวจสอบรับรอง · ไม่เกิน 2,000 บาทอนุมัติ 1 คน, เกินต้อง 2 คนต่างกันและมีแอดมิน (ปรับเกณฑ์ที่ตั้งค่า) · ผู้ขอเบิกอนุมัติของตัวเองไม่ได้
- **สมุดธนาคาร/สเตตเมนต์**: พิมพ์รายการจากสมุดคู่ฝากทีละบรรทัด (รหัส TN/DB/WB/IN/TX) หรืออัปโหลด CSV · จับคู่หลายรายการในสมุดกับยอดโอนรวมของสัปดาห์ได้ · อัปโหลด CSV (เลือกคอลัมน์ได้ จำไว้ต่อบัญชี) · แอปแนะนำคู่ที่ยอดตรงเป๊ะและวันใกล้กัน ผู้ใช้กดยืนยันเอง · อัปโหลดซ้ำไม่เกิดรายการซ้ำ
- **รายงาน**: ไม่แสดงชื่อผู้ถวาย · มีตารางตัวเลขใต้ทุกกราฟ · พิมพ์ A4 พร้อมช่องเซ็น 3 ช่อง
- สัปดาห์เริ่มวันอาทิตย์ · ปีบัญชี = ปีปฏิทิน · แสดงปี พ.ศ.

## ล้างข้อมูลทดสอบก่อนใช้จริง
- กด “ลบ” ปกติ = ซ่อน (กู้คืนได้ และให้เครื่องอื่นรับรู้การลบ) · ตั้งค่า › 🧹 ล้างข้อมูล: ลบถาวรรายการที่ลบแล้ว หรือล้างข้อมูลทั้งปี (พิมพ์ยืนยัน) ไม่แตะผู้ใช้/ประเภทถวาย/บัญชี
- ลบถาวรประทับ epoch ในไฟล์ → เครื่องอื่นรับไฟล์ออนไลน์เป็นหลัก ข้อมูลที่ลบแล้วไม่ผุดกลับ
- ประวัติ commit ของ GitHub ยังเก็บของเก่า: ถ้าต้องการสะอาด 100% ตอนเริ่มใช้จริง ให้สร้าง repo ข้อมูลใหม่แล้วเชื่อมต่อใหม่

## ความปลอดภัย (อ่านก่อนใช้จริง)
สิทธิ์เป็นการกันในแอป ไม่ใช่การล็อกระดับ GitHub: ใครมีรหัสเข้าใช้ร่วม (token ในลิงก์เชิญ) อ่านไฟล์ใน repo ข้อมูลได้ตรง ๆ จึงแจกลิงก์เฉพาะแชตส่วนตัว และเปลี่ยนรหัสเมื่อมีคนออก repo ข้อมูลต้องเป็น Private (แอปปฏิเสธการเชื่อมต่อถ้าเป็นสาธารณะ)
